# Home Builders Choice 🏗️

A web-based construction materials and equipment rental platform that allows customers to explore construction products and rent the required equipment at affordable prices.

## 📌 Project Overview

Home Builders Choice is a rental-based website developed to make construction materials and equipment accessible to customers without requiring them to purchase expensive products.

Customers can register, log in, browse available products, and contact the shop for rental enquiries.

## ✨ Features

- **User Registration:** New customers can create an account.
- **User Login:** Registered customers can securely log in.
- **Product Catalog:** Browse construction materials and equipment.
- **Rental-Based System:** Products are offered for rent rather than direct purchase.
- **Contact Us:** Customers can submit enquiries through the contact form.
- **Database Integration:** Store and manage application data using MySQL.
- **Payment Integration:** Razorpay integration (under development).

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Move the Project

Place the project folder inside:

```text
C:\xampp\htdocs\
```

### 3. Start XAMPP

- Open XAMPP Control Panel.
- Start Apache.
- Start MySQL.

### 4. Configure the Database

- Open `http://localhost/phpmyadmin/`.
- Create the required project database.
- Import the database SQL file, if available.
- Update the database connection settings in the project configuration file.

### 5. Run the Application

Open your browser and visit:

```text
http://localhost/home_builders_choice/
```
